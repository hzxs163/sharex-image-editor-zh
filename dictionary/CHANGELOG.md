# 词典版本记录

词典按"英文原文 → 中文"索引，跨 ShareX 版本复用；每次官方发版后流水线会用当版二进制重新识别界面文字，再套用本词典。

## v1 — 2026-10-14（基线，对应 ShareX 21.0.0）

- 收录 **1251** 条界面文字：标题栏、文件菜单、工具栏提示、侧栏、选项面板、新建/插入/对比/表情/背景移除等对话框、
  通知与错误提示，以及 **149 个图像效果**的名称、说明与 **549 项参数标签/选项**。
- 识别规则：只有当某字符串在本程序集里的**每一处**引用都像界面文字时才算候选；出现在
  `set_Name`、样式选择器、资源键、`PropertyChangedEventArgs`、字符串比较、`Parse` 等位置的整条放弃。
  效果参数按 `(小写键, 首字母大写标签, 格式)` 三元组结构区分键与标签。
- 刻意保留英文：`Background`、`Auto`、`Transparent`、`Rotate`、`Image`（与内部标识符共用同一字符串）、
  边框样式 `Solid` 与效果分组标题 `Manipulations / Adjustments / Filters / Drawings`（枚举 `ToString()`）、
  以及 `CRT`、`macOS`、`Windows 11`、`Emoji`、`Bayer 4x4`、`Floyd-Steinberg` 等专有名词。
- 已知副作用：效果下拉框的选项值与持久化值是同一字符串，汉化前保存的效果预设（或他人分享的 `.sxie`）
  中那些英文选项值会匹配不上，对应参数退回默认值。

### 想补词条

直接编辑 `zh_all.json` 提交即可，push 到 `main` 会自动触发重新构建与发布。
新增词条时注意：中文的 UTF-16 字节数不能超过原英文条目（补丁是等长原地替换，装不下会被跳过并在
`report.json` 的 `SKIP-TOO-LONG` 中列出）。
